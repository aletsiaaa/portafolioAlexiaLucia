# Guía rápida de entrega (27 de noviembre de 2026)

1. Descomprime el proyecto y abre la carpeta con VS Code.
2. Ejecuta `npm install` y `npm run dev` en una terminal.
3. Revisa el texto en `content/projects.ts` y ajusta cualquier detalle que no coincida con tu trabajo final.
4. Copia **tus capturas verdaderas** a `public/evidencias/` y agrégalas a la ficha de cada proyecto.
5. Edita `.env.local` con los enlaces y un correo público correctamente escrito; no publiques claves en GitHub.
6. Para habilitar el formulario, configura `RESEND_API_KEY`, `CONTACT_TO_EMAIL` y `CONTACT_FROM_EMAIL` según tu servicio. Prueba una solicitud real.
7. Revisa ortografía, enlaces y navegación, y ejecuta `npm run build`.
8. Crea tu repositorio personal, sube los archivos con `git add`, `git commit` y `git push`.
9. Importa el repositorio a Vercel, agrega variables de entorno y despliega.
10. Prueba en celular y computadora; actualiza el README con URL y captura real.
11. Personaliza el pitch de `docs/PITCH-2-MINUTOS.md` y ensáyalo en menos de dos minutos.

**Antes de hacerlo público:** el CV original contiene datos personales y referencias que se omitieron intencionalmente de la página. Confirma qué correo quieres mostrar. Los resultados numéricos y archivos que faltan deben venir de tus entregas, no de ejemplos inventados.
